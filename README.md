# InventoryOpz – Product Website (React + Vite + Tailwind)

## Run locally
    npm install
    npm run dev

## Build for deployment
    npm run build
The production build is written to `dist/`. Deploy that folder to any static host
(Vercel, Netlify, Cloudflare Pages, S3, etc.) or point your `inventory.yazhsey.in`
subdomain at it.

## Editing content
- All copy and image references live in `src/data/productData.js`.
- Real screenshots and the demo video are already wired in from `public/assets/`.
- Swap any asset by replacing the file in `public/assets/` with the same file name.
- WhatsApp number and email are set as constants at the top of `src/App.jsx`.
